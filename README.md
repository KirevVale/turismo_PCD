# Andar — Turismo accesible

Prototipo académico de una web institucional para una iniciativa de turismo accesible dirigida a personas con discapacidad visual en Cochabamba, Bolivia.

## Requisitos

- Node.js 18 o superior
- npm

## Instalación y ejecución

```bash
npm install
npm run dev
```

Vite mostrará la dirección local en la terminal. Para generar y revisar la versión de producción:

```bash
npm run build
npm run preview
```

## Antes de una presentación formal

- Sustituir las fotografías externas por imágenes propias o autorizadas y comprobar sus enlaces.
- Reemplazar el correo ficticio `hola@andar-accesible.example` por un canal real, si se habilita.
- Confirmar nombre, identidad visual y datos del negocio.
- Validar físicamente cada destino y documentar sus condiciones de accesibilidad. Las tarjetas actuales son propuestas conceptuales, no rutas auditadas.
- Revisar contraste, navegación por teclado y lector de pantalla en el entorno de presentación.

No incluye backend, cuentas, pagos, reservas ni formularios de envío. Los destinos y el contacto se muestran como contenido demostrativo.
